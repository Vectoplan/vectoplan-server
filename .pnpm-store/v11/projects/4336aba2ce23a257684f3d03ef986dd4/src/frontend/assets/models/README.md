# Avatar model assets

`vectoplan-human.glb` is the `Soldier.glb` skinned animation example distributed by the official Three.js project and credited there to Mixamo. It provides embedded `Idle`, `Walk`, and `Run` clips and is used as the default replaceable multiplayer-avatar base. The editor intentionally replaces every source material at runtime with a neutral white architectural clay material.

Source: https://threejs.org/examples/models/gltf/Soldier.glb
Example/credit: https://threejs.org/examples/webgl_animation_skinning_blending.html
Adobe Mixamo FAQ: https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html
