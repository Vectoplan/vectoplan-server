# Copy / Cut / Paste

## Zweck

Kopiert oder verschiebt einen Selection-Quader und fügt den gespeicherten Inhalt
relativ zu einem Zielpunkt ein.

## Bedienung

- Copy/Cut: Quader markieren, Operation wählen, „Ausführen“.
- Paste: Ziel anvisieren und Linksklick oder „Ausführen“ verwenden.

## Zustand

Die Zwischenablage ist ausschließlich diesem System zugeordnet. Copy und Cut
ersetzen ihren Inhalt; Paste liest ihn. Ein Reset löscht die Zielauswahl, nicht
automatisch die kopierten Daten. Flurstück- und Raumzustände werden nicht
verändert.

## Operationen

`copy`, `cut`, `paste`.
